# 1. 유틸리티 앱

## 앱 이름: DevUtils

## 카테고리: 유틸리티 앱

### 배포 링크

https://gemini.google.com/share/8a5c8057aee6

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
  : 평소 개발을 하면서 저는 마크다운 문법을 사용하는 노션과 같은 도구를 자주 사용하고, 프로젝트의 할 일을 관리하는 도구 또한 자주 사용합니다. 두 도구를 왔다갔다 하는 번거로움을 줄이기 위해 마크다운 기록과 할 일 관리 서비스를 통합하여 유용하게 사용할 수 있도록 의도하였습니다.

- 이 앱을 언제, 어떻게 사용할 건가요?
  : 우테코에서 팀 프로젝트를 진행할 때, 프로젝트의 제가 맡은 부분을 여러 섹션으로 나누고 그 섹션에 맞게 여러 할 일을 정리할 것이며 할 일을 체크하며 완료해나가면서 섹션에 해당하는 내용으로 개발 일지를 작성할 것입니다.

### 주요 기능

- 홈 대시보드
  : 깃허브 스타일의 최근 한 달 간의 활동 잔디 그래프, 전체 통계, 오늘/내일 마감인 할 일 모아보기 기능을 제공합니다.
- 개발 일지
  : 마크다운 파서를 통해 실시간으로 렌더링되는 에디터를 지원하여 개발 일지를 작성할 수 있습니다. 작성한 일지들은 수정이나 삭제가 자유롭고, 그리드 형태의 카드로 보관되며 제목 검색 및 6개 단위의 페이지네이션 기능을 제공합니다.
- 할 일 관리
  : 스프린트나 기능별로 '섹션'을 나누고 하위에 할 일을 추가할 수 있으며, 할 일은 마감일을 설정할 수 있습니다. 전체 진행도를 프로그래스 바로 보여주며, 섹션 검색 기능 및 4개 단위 페이지네이션, 섹션 아코디언 UI 기능을 제공합니다.
